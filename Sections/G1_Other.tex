\section{Data availability}
Custom software developed for the purpose of execution of optimisation
 routines is available under the `BO4ACST' project lodged in github at
 the following address: https://github.com/ThomasDodd97/BO4ACST\_Ax1.

The latex project associated with this paper has been made available
 under the `UoC\_Paper2' project lodged in github at the following 
 address: https://github.com/ThomasDodd97/UoC\_Paper2.

Furthermore, it may be noted that the `Sandbox' directory within the
 `UoC\_Paper2' project contains both the data and the jupyter notebooks
 required to process it into the graphics depicted in the present work.
